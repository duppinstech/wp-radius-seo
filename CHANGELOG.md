# Changelog

Release notes are maintained in **`readme.txt`** in WordPress readme format (stable tag, version headings, bullet lists). GitHub Releases mirror shipped ZIPs and often paste the same summary.

- **WordPress-style changelog:** [`readme.txt`](readme.txt) → *Changelog* section  
- **GitHub releases:** [github.com/duppinstech/wp-radius-seo/releases](https://github.com/duppinstech/wp-radius-seo/releases)

This file exists so visitors looking for `CHANGELOG.md` find a single source of truth and avoid duplicated histories.

The format of this file is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).
