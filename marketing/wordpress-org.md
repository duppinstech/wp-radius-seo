# WordPress.org listing notes

Not submitted. These are the screenshots and captions to use if Radius SEO is listed in the plugin directory. The directory wants the admin screens where an owner configures the plugin, not only the public pages.

Use the files in `marketing/screenshots/admin/`. Suggested order and captions:

1. `dashboard.jpg` — Radius adds one menu. Templates, the location library, and Deploy are the path from a blueprint to published pages.
2. `template-edit.jpg` — Write the page once. Tokens such as {{place_name}} are filled when you deploy.
3. `locations.jpg` — Import a CSV of places. A name, latitude, and longitude are what deploy needs.
4. `settings-areas.jpg` — A service area is a place from the library plus a radius in miles.
5. `deploy-run.jpg` — Deploy and update all places writes one current page per place in range.
6. `settings-general.jpg` — The service-area prefix is for hub URLs. Landings stay at the site root.
7. `license.jpg` — Paste the license key, or purchase a plan, on Settings → License.
