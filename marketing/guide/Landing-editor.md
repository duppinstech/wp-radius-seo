# Edit one landing

Open a row under Radius → Landings. This is one published page. The template and the place stored on it are how Radius finds this page on the next deploy.

## Steps

1. Change the copy only if this city must differ from the template for now.
2. Update the page.
3. Leave the template and place fields filled in. If you clear them, the next deploy cannot match this page and may create another one.
4. Expect the next deploy of this template and place to rewrite the page from the template. Your one-off edit does not survive that deploy.

To change every city, edit the template instead. See [Template editor](Template-editor).
