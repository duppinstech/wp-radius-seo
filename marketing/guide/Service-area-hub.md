# Edit one hub

Open a row under Radius → Service areas. This page is one hub for one place.

## Steps

1. Edit the hub only for a temporary, one-place change.
2. Update.
3. Leave the template and place stored on the page so the next service-area deploy updates this hub instead of creating another.
4. The next service-area deploy rewrites this hub from the service-area template.
