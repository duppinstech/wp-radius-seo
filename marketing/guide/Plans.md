# Plans

Checkout is on Stripe. After checkout, Duppins Technology sends a license key. Paste it under Radius → Settings → License. The plugin does not see the payment.

| Plan | Price | What you get |
| --- | --- | --- |
| Single site | $9.99 per month | One site, email support |
| Unlimited sites | $99 per month | Unlimited sites, priority email support |

- Purchase single site: https://buy.stripe.com/6oU7sK8Yt9hag4f0iJ00007
- Purchase unlimited sites: https://buy.stripe.com/4gM5kCeiN9ha8BN6H700008

A signed key can be labeled single site or unlimited. A key already saved on a site keeps working until it is replaced. Cancelling the Stripe subscription does not yet turn that key off, because there is no license server. One key is not refused on a second site until that server exists. Priority email for the unlimited plan is flagged in the Duppins Technology account. The plugin does not store or check that flag.
