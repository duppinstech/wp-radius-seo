# Radius SEO user guide

This is the guide opened by the Help button inside the plugin. Each Radius screen opens this page at the section for that screen.

Radius SEO turns one template and a place library into local landing pages and service-area hubs. You write the page once. Tokens fill in the city, the phone number, and the rest of your details when each page is published. A second deploy updates those pages. It does not add a second copy.

## Do the work in this order

1. [Install](Install) the plugin and activate it.
2. [License](License). Paste the signed key and save it. Until a key is saved, templates, the library, and deploy stay locked.
3. [Location library](Location-library). Radius does not download cities. Upload a CSV that has a name, latitude, and longitude.
4. [Service area circles](Settings-service-areas). Pick a center place and a radius in miles. Save. Deploy stays off until this exists.
5. [Templates](Templates). Write one blueprint. Put `{{place_name}}` in the title and body.
6. [Site replacers](Settings-replacers). Set the company name and phone number those tokens will use.
7. [Deploy](Deploy). On the template card, choose Deploy & update all places.

Then use [Landings](Landings) to see the city pages, and [Service area hubs](Service-area-hubs) to see the hub pages.
