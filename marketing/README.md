# Radius SEO marketing

Copy for the Duppins Technology website and for social posts. These files are not part of the installable plugin.

Support for the product is support@duppinstech.com or (240) 397-8221.

## Files

- `website.md` — sections to place on a product page
- `guide/` — the full page-by-page user guide. `guide/PROMPT.md` is the instruction for the website AI. `radius-seo-guide-pack.zip` is that folder plus the screenshots, ready to hand to that AI.
- `admin-walkthrough.md` — short setup order. The long version is `guide/`.
- `wordpress-org.md` — admin screenshots and captions if the plugin is listed in the directory
- `social.md` — posts that can be copied
- `quick-guide.md` — a short how-it-works sheet
- `screenshots/admin/` — wp-admin screens with numbered arrows (setup)
