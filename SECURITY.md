# Security policy

## Supported versions

Security fixes are applied to the **latest release** on [`main`](https://github.com/oduppinsjr/wp-radius-seo) and shipped via [GitHub Releases](https://github.com/oduppinsjr/wp-radius-seo/releases). Use the newest tagged version where possible.

Older releases are **not** guaranteed long-term support; upgrade through **Dashboard → Updates** (when using the bundled GitHub updater) or by uploading the current release ZIP.

## Reporting a vulnerability

Please **do not** open a public issue for undisclosed security problems.

1. **Preferred:** [Open a GitHub Security Advisory](https://github.com/oduppinsjr/wp-radius-seo/security/advisories/new) for this repository (private submission to maintainers).
2. **Alternative:** Email **security@duppinstech.com** with enough detail to reproduce (WordPress version, PHP version, affected Radius SEO version, steps, impact). Encrypt if your organization requires it (request a key if needed).

We aim to acknowledge receipt within a few business days and coordinate disclosure after a fix is available.

## Scope

Reports should concern **this plugin** (`wp-radius-seo`). Issues in WordPress core, PHP, hosting, or third-party plugins/themes are outside maintainer control but may be noted for awareness.

## Safe harbor

We appreciate responsible disclosure and collaborative fixes.
