# Department meeting — 2026-10-14 15:56

Interface only. This department was not at the 15:44 meeting. The Radius menu was reviewed as it stands. No product code was changed.

## Suggested

- **Interface.** Keep the single Radius menu. The migration wizard, the site-replacements dialog, and the spintax dialog never take focus and do not close on Escape. Deploy help is closer, and it still lets Tab leave the dialog. The license lock dims screens with `pointer-events: none`, so the keyboard can still operate them. Location-library checkboxes, both CSV file fields, and service-area search and radius fields have no accessible name. Deploy status text is not a live region. Analytics charts are canvases without a text alternative, and two data tables use headers without `scope`. None of this needs a maintainer decision. The Radius menu does not move.
